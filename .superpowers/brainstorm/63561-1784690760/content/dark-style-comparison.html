对比分析

A) 深灰/石墨
  • 温暖、柔和
  • 层次感一般
  • 卡片与背景区分不够
B) 纯黑 OLED
  • 极简、省电
  • 对比度过高易疲劳
  • 无层次感，扁平化
C) 偏蓝暗黑 ⭐
  • 与 #2196F3 蓝色最和谐
  • 带边框的卡片层次清晰
  • 专业感强，类似 VS Code / GitHub

推荐理由

项目主题蓝 #2196F3 已有 50+ 处使用。偏蓝暗黑底色（#0d1117）带冷蓝调，与现有蓝色天然搭配，无需调整主色调。
边框分割线 #21262d 让卡片层次关系比 A 方案更清晰，比 B 方案更有呼吸感。
这是 GitHub、VS Code 暗黑主题验证过的成熟搭配模式。
