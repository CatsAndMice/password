密码管家项目的主题实现概览

当前架构

工作现状

  • 三态切换：亮色 / 暗黑 / 跟随系统
  • data-theme 属性控制，通过 localStorage 持久化
  • Header 组件提供用户切换入口

核心问题

  • 暗黑模式使用 filter: invert(1) hue-rotate(180deg) 全局翻转
  • 零个 CSS Custom Properties
  • 约 200+ 处硬编码颜色散布在 20+ 文件
  • MUI ThemeProvider 未启用，默认调色板
  • 无 Tailwind dark: 变体
